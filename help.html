First-aid basics, how the app works, and what to do if something isn't working.

Active emergency? Call your local emergency number now (in India: 108 or 112) in addition to using this app.

Snakebite first aid

Keep the person calm and as still as possible — movement speeds venom spread. Keep the bitten limb below heart level and loosely immobilized (a splint helps). Remove rings, watches, or tight clothing near the bite before swelling starts. Get to a hospital immediately.
Don't apply a tight tourniquet, cut the wound, try to suck out venom, apply ice, or give the person alcohol or caffeine. None of these help, and several can cause additional harm.

Using this app

If you select a snake manually because you know what it was, that's as accurate as your own identification. The photo-analysis option is an automated estimate, not a diagnosis — it can be wrong, especially with unclear photos, which is why you're always asked to confirm or correct it before continuing.
Green: stock reported available within the last hour. Yellow: reported available, but the update is older — call ahead to confirm. Red: not currently reported as available at that hospital.
Hospitals register themselves, but every new registration starts as "pending" and is reviewed by the site operator before it appears publicly. This prevents fake or unverified hospital entries from showing up in search results.
Hospital stock levels are public by design — that's the point of the app. If you submit the optional incident report, your notes and phone number (if provided) are stored in the app's database for regional tracking purposes and aren't displayed publicly.

Something not working?

Use the chat assistant on the main page for quick questions. For technical issues (the app won't start, an error appears, a page looks broken), note the exact error message and check the project's README file for troubleshooting steps.
